TypeScript কী?

TypeScript হলো JavaScript-এর একটি সুপারসেট যা Microsoft দ্বারা তৈরি করা হয়েছে। এটি মূলত JavaScript-এর কার্যকারিতাকে আরও শক্তিশালী ও নির্ভরযোগ্য করার জন্য ডিজাইন করা হয়েছে, বিশেষ করে বড় আকারের অ্যাপ্লিকেশনের জন্য।

কেন TypeScript ব্যবহার করবেন?

বৈশিষ্ট্য সুবিধা
স্ট্যাটিক টাইপিং (Static Typing) কোড লেখার সময় ভেরিয়েবল এবং ফাংশনের টাইপ নির্দিষ্ট করা যায়, যা রানটাইম এরর কমায়।
উন্নত এডিটর সাপোর্ট VS Code-এ অটো-কমপ্লিশন, ইন্টেলিসেন্স এবং রিফ্যাক্টিং করা সহজ হয়।
OOP সুবিধা ক্লাস, ইন্টারফেস, ইনহেরিটেন্স ইত্যাদি ব্যবহার করে বড় কোডবেস পরিচালনা করা সহজ।

Primitive Data Types

Primitive Data Types হলো TypeScript-এর সবচেয়ে মৌলিক ডেটা টাইপ। এগুলো মেমোরিতে সরাসরি মান (Value) হিসেবে সংরক্ষিত থাকে।

TypeScript 
// Primitive Types Examples

let userName: string = "Anisul Islam";
let age: number = 25;
let isAdmin: boolean = true;

// Null & Undefined
let x: undefined = undefined;
let emptyValue: null = null;

Array Type

অ্যারেতে একটি নির্দিষ্ট টাইপের একাধিক উপাদান সংরক্ষণ করা যায়।

TypeScript 
// Syntax 1
let numbers: number[] = [1, 2, 3];

// Syntax 2 (Generic)
let names: Array<string> = ["Rahim", "Karim"];

Non-Primitive Data Types

এগুলো একাধিক মান বা জটিল ডেটা স্ট্রাকচার ধারণ করে এবং মেমোরিতে রেফারেন্স (Reference) হিসেবে থাকে।

TypeScript 
// 1. Array
let friends: string[] = ["Rahim", "Karim"];

// 2. Object (Key-Value Pair)
let user: { name: string; age: number } = {
  name: "Shakib",
  age: 30
};

// 3. Tuple (Fixed length & type)
let role: [string, number] = ["Manager", 101];

// 4. Enum (Named constants)
enum Status {
  Pending,
  Approved,
  Rejected
}
let currentStatus: Status = Status.Approved;

Object Literal & Optional Properties

অবজেক্ট লিটারেল হলো অবজেক্ট তৈরির সবচেয়ে সহজ পদ্ধতি। যদি কোনো প্রপার্টি থাকাও না-থাকাও পারে, তবে আমরা ? (Optional) চিহ্ন ব্যবহার করি।

TypeScript 
let student: {
  name: string;
  id: number;
  phone?: string; // Optional Property
  address?: string; // Optional Property
} = {
  name: "Mehedi Hasan",
  id: 2204
  // phone এবং address না দিলেও কোড রান করবে
};

// Optional Chaining
console.log(student.phone?.toUpperCase());

Functions (ফাংশন)

TypeScript-এ ফাংশনের প্যারামিটার এবং রিটার্ন ভ্যালুর টাইপ আগে থেকেই নির্দিষ্ট করে দেওয়া যায়।

TypeScript 
// ১. Basic Function
function add(a: number, b: number): number {
  return a + b;
}

// ২. Arrow Function
const multiply = (x: number, y: number): number => {
  return x * y;
};

// ৩. Optional Parameters (?)
function greet(name: string, message?: string): string {
  if (message) {
    return `Hello ${name}, ${message}`;
  }
  return `Hello ${name}`;
}

Interface with Methods

ইন্টারফেস অবজেক্টের স্ট্রাকচার বর্ণনা করে, এমনকি এর ভেতরে মেথডও থাকতে পারে।

TypeScript 
interface User {
  firstName: string;
  lastName: string;
  age: number;
  
  // Method Signature
  getFullName(): string;
  updateAge(newAge: number): void;
}

const myUser: User = {
  firstName: "Sakib",
  lastName: "Al Hasan",
  age: 34,
  
  getFullName() {
    return `${this.firstName} ${this.lastName}`;
  },
  
  updateAge(newAge: number) {
    this.age = newAge;
  }
};

Rest vs Spread Operator (...)

দুটির মধ্যে পার্থক্য হলো: Rest মানে "একত্রিত করা" (Pack) এবং Spread মানে "ছড়িয়ে দেওয়া" (Unpack)।

TypeScript 
// --- A. Rest Operator (Pack) ---
// ফাংশনে অনির্দিষ্ট সংখ্যক ইনপুট নেওয়া
function sumAll(...numbers: number[]): void {
  const total = numbers.reduce((acc, num) => acc + num, 0);
  console.log("Total:", total);
}

sumAll(10, 20, 30);

// --- B. Spread Operator (Unpack) ---
// অ্যারে কপি বা মার্জ করা
const teamA = ["Rahim", "Karim"];
const teamB = ["Jabbar", "Salam"];

const fullTeam = [...teamA, ...teamB, "Barkat"];

Destructuring

অ্যারে বা অবজেক্ট থেকে ভ্যালু আলাদা আলাদা ভেরিয়েবলে রাখার প্রক্রিয়া।

TypeScript 
// 1. Object Destructuring
const user = {
  id: 101,
  fullName: "Mehedi Hasan",
  age: 25
};

const { fullName, age } = user;

// 2. Array Destructuring
const colors: string[] = ["Red", "Green", "Blue"];
const [color1, , color3] = colors; // Green স্কিপ করা হয়েছে

Type Alias

টাইপ অ্যালিয়াস হলো কোনো টাইপের একটি কাস্টম নাম বা ডাকনাম দেওয়া।

TypeScript 
// 1. Object Type Alias
type Student = {
  id: number;
  name: string;
};

const student1: Student = {
  id: 101,
  name: "Rahim"
};

// 2. Union Type Alias
type ID = number | string;

let userId: ID;
userId = 101;      // Valid
userId = "U-101"; // Valid

Union vs Intersection Types

  • Union (|): অথবা (OR)। "হয় এটা হবে, না হয় ওটা হবে"।
  • Intersection (&): এবং (AND)। "দুটোই একসাথে লাগবে"।
TypeScript 
// Union Type
let userId: string | number;
userId = "U-505";

// Intersection Type
type FrontendDev = { skills: string[] };
type BackendDev = { database: string };

// FullStackDev এর মধ্যে Frontend ও Backend দুটোর প্রপার্টিই থাকতে হবে
type FullStackDev = FrontendDev & BackendDev;

Modern Operators

1. Ternary Operator (? :)

if-else এর এক লাইনের শর্টকাট।

TypeScript 
const age = 20;
const type: string = age >= 18 ? "Adult" : "Child";

2. Nullish Coalescing (??)

ভ্যালু null বা undefined হলে ডিফল্ট ভ্যালু সেট করে। || এর মতো নয়, এটি 0 বা "" কে ফলস বলে না।

TypeScript 
const isAuthenticated = null;
const userName = isAuthenticated ?? "Guest"; // "Guest"

const testNumber = 0;
const result = testNumber ?? 10; // 0 (কারণ 0 ফলস নয়)

3. Optional Chaining (?.)

নেস্টেড অবজেক্ট এক্সেস করার সময় ভুল হলে ক্র্যাশ না করে undefined রিটার্ন করে।

TypeScript 
const roadName = user.address?.road ?? "No Road";

Nullable, Unknown & Never

Nullable Types

ভেরিয়েবল null বা undefined রাখতে পারে কিনা তা নির্দিষ্ট করা।

TypeScript 
let myName: string | null;
myName = null; // Valid

Unknown Type

any এর মতোই, কিন্তু নিরাপদ। ব্যবহার করার আগে টাইপ চেক করতে হয়।

TypeScript 
let guestInput: unknown;
guestInput = "Hello";

if (typeof guestInput === "string") {
  console.log(guestInput.toUpperCase()); // Safe to use
}

Type Assertion

কম্পাইলারকে জোর করে বলা যে ভেরিয়েবলটির টাইপ কী।

TypeScript 
let someValue: unknown = "This is a string";

// 'as' Syntax (Recommended)
let strLength: number = (someValue as string).length;

// DOM Manipulation
const myInput = document.getElementById("user-input") as HTMLInputElement;
console.log(myInput.value);

Interface (ইন্টারফেস)

ইন্টারফেস হলো অবজেক্টের স্ট্রাকচার বা চুক্তি (Contract) ডিফাইন করার জন্য ব্যবহৃত হয়।

TypeScript 
interface User {
  readonly id: number; // পরিবর্তনযোগ্য নয়
  name: string;
  age?: number; // Optional
}

// Extending Interface (Inheritance)
interface Employee extends User {
  salary: number;
  position: string;
}

Generics: Type Alias

টাইপ অ্যালিয়াসকে ডায়নামিক বা রিইউজেবল করার জন্য জেনেরিক্স ব্যবহার করা হয়।

TypeScript 
// T হলো একটি প্লেসহোল্ডার
type Box<T> = {
  content: T;
};

const stringBox: Box<string> = { content: "চিঠি" };
const numberBox: Box<number> = { content: 500 };

// Utility Type Example
type Maybe<T> = T | null;

Generics: Interface

API রেসপন্স হ্যান্ডেল করার জন্য এটি খুবই কার্যকর।

TypeScript 
interface ApiResponse<T> {
  status: number;
  message: string;
  data: T; // ডেটা টাইপ ডায়নামিক
}

interface User {
  name: string;
  age: number;
}

// User ডেটার জন্য
const userResponse: ApiResponse<User> = {
  status: 200,
  message: "User found",
  data: { name: "Fahim", age: 28 }
};

Generics in Function

ফাংশন যেন যেকোনো টাইপের ইনপুট নিতে পারে এবং সেই অনুযায়ী আউটপুট দিতে পারে।

TypeScript 
// Basic Generic Function
function showData<T>(data: T): T {
  return data;
}

// Array Generic Function
const getFirstItem = <T>(arr: T[]): T => {
  return arr[0];
};

const firstNum = getFirstItem([10, 20, 30]); // Type: number
