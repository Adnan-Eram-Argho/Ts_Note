1. Introduction to TypeScript

Concept: TypeScript হলো JavaScript-এর একটি সুপারসেট যা Microsoft দ্বারা তৈরি করা হয়েছে। এটি মূলত JavaScript-এর কার্যকারিতাকে আরও শক্তিশালী ও নির্ভরযোগ্য করার জন্য ডিজাইন করা হয়েছে, বিশেষ করে বড় আকারের অ্যাপ্লিকেশনের জন্য।

কেন TypeScript ব্যবহার করব?

  • Static Typing: কোড লেখার সময় ভেরিয়েবল, ফাংশন প্যারামিটার এবং রিটার্ন ভ্যালুর জন্য টাইপ নির্দিষ্ট করার অনুমতি দেয়।
  • Early Error Detection: কম্পাইল করার আগেই টাইপ-সংক্রান্ত ত্রুটি ধরা পড়ে, ফলে রানটাইম ত্রুটি কমে যায়।
  • Tooling Support: VS Code-এর মতো এডিটরে অটো-কমপ্লিশন এবং রিফ্যাক্টরিং সুবিধা পাওয়া যায়।
Beginner Tip ⚠️ TypeScript সরাসরি ব্রাউজারে রান করে না। প্রথমে একে JavaScript (.js) এ কম্পাইল করতে হয়।

2. Type System Fundamentals

TypeScript-এর মূল ভিত্তি হলো টাইপ সিস্টেম। এটি নিশ্চিত করে যে আপনার কোড ঠিকমতো ডাটা হ্যান্ডেল করছে।

Static Typing vs Dynamic

JavaScript ডাইনামিক টাইপড (ভেরিয়েবল ঘুরে ফিরে টাইপ বদলাতে পারে), কিন্তু TypeScript স্ট্যাটিক টাইপড (টাইপ একবার সেট করলে আর বদলায় না)।

let a: number = 10;
// a = "hello"; // Error: Type 'string' is not assignable to type 'number'

3. Primitive Data Types

Concept: Primitive Data Types হলো TypeScript (এবং JavaScript)-এর সবচেয়ে মৌলিক বা বেসিক ডাটা টাইপ। এগুলা হলো একদম লো-লেভেল ডাটা ভ্যালু যা মেমরিতে সরাসরি মান (Value) হিসেবে সংরক্ষিত থাকে।

// 1. String: টেক্সট ডাটার জন্য
let userName: string = "Anisul Islam";

// 2. Number: পূর্ণসংখ্যা বা দশমিক সংখ্যার জন্য
let age: number = 25;
let price: number = 99.99;

// 3. Boolean: শুধুমাত্র true অথবা false এর জন্য
let isAdmin: boolean = true;

// 4. Undefined: ভেরিয়েবল ডিক্লয়ার করা হয়েছ কিন্তু ভ্যালু দেওয়া হয়নি
let x: undefined = undefined;

// 5. Null: যখন আমরা ইচ্ছাকৃতভাবে কোনো ভ্যালু খালি রাখতে চাই
let emptyValue: null = null;

4. Non-Primitive (Reference) Types

Concept: Non-Primitive Types হলো এমন ডাটা টাইপ যা একাধিক মান বা জটিল ডাটা স্ট্রাকচার ধারণ করতে পারে। এরা মেমরিতে সরাসরি ভ্যালু হিসেবে থাকে না, বরং মেমরির লোকেশনের রেফারেন্স হিসেবে থাকে।

  • Array: তালিকা।
  • Object: কি-ভ্যালু পেয়ার।
  • Tuple: ফিক্সড টাইপের অ্যারে।
  • Enum: নেমড কনস্ট্যান্টস।

5. Array Types

অ্যারেতে একটি নির্দিষ্ট টাইপের একাধিক উপাদান সংরক্ষণ করা যায়।

// Syntax 1: type[]
let numbers: number[] = [1, 2, 3];
let names: string[] = ["ক", "খ"];

// Syntax 2 (Generic Array Type): Array
let list: Array = [4, 5, 6];

6. Object Types

অবজেক্ট টাইপ ব্যবহার করে ডাটা স্ট্রাকচার ডিফাইন করা হয়।

let user: { name: string; age: number; isAdmin: boolean } = {
    name: "Shakib",
    age: 30,
    isAdmin: true
};

7. Optional Properties & Optional Chaining

Concept: অনেক সময় অবজেক্টের সব প্রপার্টি আমাদের দরকার হয় না। তখন আমরা ? চিহ্ন ব্যবহার করি।

let student: {
    name: string;
    id: number;
    phone?: string; // Optional Property
} = {
    name: "Mehedi",
    id: 2204
    // phone না দিলেও কোড রান করবে
};

// Optional Chaining (?.)
console.log(student.phone?.toUpperCase()); // phone undefined হলে error দেবে না

8. Functions in TypeScript

TypeScript-এ ফাংশন সংজ্ঞায়িত করার সময় আমরা প্যারামিটার এবং রিটার্ন ভ্যালু টাইপ নির্দিষ্ট করে দিতে পারি।

// Parameter এবং Return Type সহ
function add(a: number, b: number): number {
    return a + b;
}

// Optional Parameters (?)
function greet(name: string, message?: string): string {
    if (message) return `Hello ${name}, ${message}`;
    return `Hello ${name}`;
}

// Default Parameters (=)
function power(base: number, exponent: number = 2): number {
    return base ** exponent;
}

// Rest Parameters (...)
function sumAll(...numbers: number[]): number {
    return numbers.reduce((total, num) => total + num, 0);
}

// Void Return Type
function logMessage(msg: string): void {
    console.log(msg);
}
Interview Note 💡 Arrow Function-এ this keyword নিজস্ব scope ধারণ করে না, এটি enclosing scope থেকে নেয়। অবজেক্ট মেথড হিসেবে সাধারণ ফাংশন ব্যবহার করা নিরাপদ।

9. Classes

TypeScript ক্লাস ES6 সিনট্যাক্সের উপর ভিত্তি করে তৈরি হয়েছ এবং এতে অ্যাক্সেস মডিফায়ার বা টাইপ সুবিধা রয়েছ।

class Animal {
    // Properties
    private name: string; 

    constructor(theName: string) {
        this.name = theName;
    }

    // Method
    move(distanceInMeters: number = 0) {
        console.log(`${this.name} ${distanceInMeters} মিটার দূরত্ব অতিক্রম করেছ।`);
    }
}

10. Encapsulation

Concept: ডাটা এবং মেথডকে একসাথে রাখা এবং বাইরে থেকে সরাসরি অ্যাক্সেস রোধ করা।

  • private: শুধুমাত্র ক্লাসের ভেতর অ্যাক্সেসযোগ্য।
  • protected: ক্লাস এবং এর চাইল্ড ক্লাসে অ্যাক্সেসযোগ্য।
  • public: সবখানে অ্যাক্সেসযোগ্য (Default)।

11. Inheritance

extends কিওয়ার্ড ব্যবহার করে একটি ক্লাস অন্য একটি ক্লাসের বৈশিষ্ট্য উত্তরাধিকার সূত্রে পায়।

class Dog extends Animal {
    bark() {
        console.log('ঘউ ঘউ!');
    }
    
    move(distanceInMeters = 5) {
        console.log("দৌড়াচ্ছ...");
        super.move(distanceInMeters); // বেস ক্লাসের move মেথড কল
    }
}

12. Polymorphism

Concept: একই ইন্টারফেস বা মেথডের বিভিন্ন আচরণ। চাইল্ড ক্লাস প্যারেন্ট ক্লাসের মেথডকে নিজের মতো করে রি-রাইট (Override) করতে পারে।

// উদাহরণ: Topic 11 এর Dog ক্লাস দেখুন।
// Dog ক্লাস Animal এর move() মেথডকে পরিবর্তন করেছে।
let myDog = new Dog("Tommy");
myDog.move(10); // Dog এর কাস্টম move কল হবে

13. Abstraction

Concept: ইমপ্লিমেন্টেশন ডিটেইল লুকিয়ে রেখে শুধুমাত্র ফাংশনালিটি ফোকাস করা।

TS-এ abstract ক্লাস এবং মেথড ব্যবহার করা হয়। Abstract ক্লাসকে সরাসরি Instantiate করা যায় না।

abstract class Vehicle {
    abstract move(): void; // ইমপ্লিমেন্টেশন নেই, শুধু সিগনেচার আছে
}

class Car extends Vehicle {
    move() {
        console.log("Car is moving");
    }
}

14. Interfaces

ইন্টারফেস হলো একটি স্ট্রাকচারাল চুক্তি যা অবজেক্টের আকার বর্ণনা করতে ব্যবৃত হয়।

interface Person {
    firstName: string;
    lastName: string;
    age?: number; // Optional
}

// Extending Interface
interface Employee extends Person {
    salary: number;
}

const emp1: Employee = {
    firstName: "Rahim",
    lastName: "Khan",
    salary: 50000
};
Beginner Tip ⚠️ Interface শুধুমাত্র অবজেক্টের স্ট্রাকচার ডিফাইন করতে ব্যবৃত হয়, Union টাইপ বা Primitives এর জন্য Type Alias ব্যবহার করুন।

15. Type Alias

আমরা যেকোনো টাইপের একটি নিজস্ব নাম (Custom Name) দিতে পারি।

// Primitive Alias
type UserName = string;

// Object Alias
type Student = {
    id: number;
    name: string;
};

// Union Type Alias
type ID = number | string;

16. Union Types ( | )

Concept: "অথবা" (OR) লজিক। ভেরিয়েবলের মান একাধিক টাইপের হতে পারে।

let userId: string | number;
userId = 101; // OK
userId = "U-505"; // OK

function showId(id: string | number) {
    if (typeof id === "string") {
        console.log(id.toUpperCase());
    } else {
        console.log(id.toFixed());
    }
}

17. Intersection Types ( & )

Concept: "এবং" (AND) লজিক। দুটি টাইপকে জোড়া লাগিয়ে নতুন শক্তিশালী টাইপ তৈরি।

type FrontendDev = { skills: string[] };
type BackendDev = { database: string };

type FullStackDev = FrontendDev & BackendDev;

const dev: FullStackDev = {
    skills: ["React"],
    database: "MongoDB"
};

18. Modern Operators

  • Ternary (? :): if-else এর শর্টকাট।
  • Nullish Coalescing (??): null বা undefined হলে ডিফল্ট ভ্যালু দেয়।
  • Optional Chaining (?.): নেস্টেড অবজেক্ট এক্সেস করার সময় নিরাপত্তা।
// Ternary
const type = age >= 18 ? "Adult" : "Child";

// Nullish Coalescing (??) vs OR (||)
// ?? শুধুমাত্র null/undefined চেক করে, 0 বা "" কে সত্য বলে ধরে।
const val = testNumber ?? 10;

// Optional Chaining
console.log(user.address?.city);

19. Nullable Types

Strict Mode-এ কোনো ভেরিয়েবল null রাখা যায় না, যদি না আমরা Union টাইপ ব্যবহার করি।

let searchName: string | null;
searchName = null; // Valid

20. Unknown vs Any

  • any: টাইপ চেকিং বন্ধ করে দেয়। (ঝুঁকিপূর্ণ)
  • unknown: টাইপ চেক না করা পর্যন্ত ব্যবহার করতে দেয় না। (নিরাপদ)
Common Mistake any ব্যবহার করলে টাইপ সুরক্ষা চলে যায়। সম্ভব হলে unknown ব্যবহার করুন এবং typeof দিয়ে চেক করুন।

21. Never Type

never টাইপ এমন ভ্যালুকে নির্দেশ করে যা কখনো ঘটে না (যেমন: এরর থ্রো করা বা ইনফিনিটি লুপ)।

function throwError(message: string): never {
    throw new Error(message);
}

22. Type Assertion

কম্পাইলারকে জোর করে বলা যে ভেরিয়েবলটির টাইপ কী।

// as syntax (Recommended)
let someValue: unknown = "Hello";
let strLength: number = (someValue as string).length;

// DOM Assertion
const input = document.getElementById("input") as HTMLInputElement;
console.log(input.value);

23. Destructuring

অ্যারে বা অবজেক্ট থেকে ভ্যালু আলাদা আলাদা ভেরিয়েবলে রাখা।

// Array Destructuring
const numbers = [1, 2, 3];
const [first, second] = numbers;

// Object Destructuring
const user = { name: "Rahim", age: 25 };
const { name, age } = user;

// Renaming
const { name: myName } = user;

24. Rest vs Spread Operator

  • Rest (...): অনেকগুলো ভ্যালুকে একটি অ্যারেতে প্যাক করা।
  • Spread (...): অ্যারে বা অবজেক্টকে ছড়িয়ে দেওয়া (Unpack)।
// Rest
function sumAll(...nums: number[]) { }

// Spread (Merge objects)
const newObj = { ...oldObj, newProp: true };

25. Generics with Type Alias

টাইপ এলিয়াস ব্যবহার করে ডাইনামিক বা ভেরিয়েবল টাইপ তৈরি করা।

type Box = {
    content: T;
};

const stringBox: Box = { content: "Hello" };
const numberBox: Box = { content: 100 };

// Utility Pattern
type Maybe = T | null;

26. Generics with Interface & Function

ইন্টারফেস এবং ফাংশনে জেনেরিক্স ব্যবহার করে রি-ইউজেবল কোড লেখা।

// Generic Interface
interface ApiResponse {
    status: number;
    data: T;
}

const res: ApiResponse = { status: 200, data: userObj };

// Generic Function
function identity(arg: T): T {
    return arg;
}

// Generic Constraints (extends)
interface Lengthwise {
    length: number;
}
function loggingIdentity(arg: T): T {
    console.log(arg.length); // এখন .length এক্সেস করা নিরাপদ
    return arg;
}
Interview Note 💡 জেনেরিক্স ব্যবহার করলে কম্পোনেন্ট বা ফাংশন যেকোনো ডাটা টাইপ হ্যান্ডেল করতে পারে, কিন্তু টাইপ সেফটি বজায় থাকে।
